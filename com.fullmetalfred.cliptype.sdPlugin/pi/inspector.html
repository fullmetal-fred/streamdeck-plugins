ClipType Settings
Char Delay (ms)
Delay between each keystroke. Increase if the target console drops characters.
Line Delay (ms)
Extra delay after pressing Enter. Useful for slow remote consoles.
Max Length
Maximum number of characters to type. Safety limit to prevent accidental mega-pastes.
How it works

Press the button to type whatever is on your clipboard, one keystroke at a time. This works in remote consoles (iLO, iDRAC, KVM, vSphere, etc.) where Ctrl+V doesn't work.

Setup: The ClipType helper must be running in the background. See the README for installation instructions.
